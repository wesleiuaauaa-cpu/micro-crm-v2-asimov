# n8n-ia-faq-whatsapp

Este projeto implementa um FAQ automatizado no WhatsApp usando **n8n** integrado com um agente de IA.  

---

## 📂 Arquivos do projeto

- **README.md**  
  Documento de referência do projeto.  

- **ai-agent-prompt.md**  
  Contém o prompt usado para configurar o agente de IA, definindo como ele deve responder às perguntas.  

- **n8n-workflow.json**  
  Workflow exportado do n8n. Pode ser importado diretamente para montar a automação no seu ambiente.
